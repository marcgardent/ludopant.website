BaseNode Packs

Libraries of node groups for Blender 5.2 and later, written as text and tested against Blender at each release.

The packs are written in Base Node, an open source text language for Blender's node trees: Geometry Nodes, shaders and the compositor. The language, the add-on and its free modules are on the Base Node site. Each pack adds modules of node groups for one craft, and a tutorial that builds a scene with them, step by step.

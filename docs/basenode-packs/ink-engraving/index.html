Strokes that live (taper, wobble, bleed, write-on), engraving cross-hatching, guilloché, halftone and Lehmann slope hachures, and deformation along curves with Frenet frames, ribbons and arrowheads.

The modules

A module is a .bn file of node groups. Once the pack is installed, a graph calls it with use, and Blender builds its groups.

ModuleWhat it gives
deform2dFrenet-Serret 2D moving frames, flow along curve deformation, ribbon outlines, and parametric arrowheads
hachures2dEngraving cross-hatching, guilloché security patterns, screentone halftone dots, and Lehmann slope hachures
ink2dLiving ink, organic stroke dynamics, taper, wobble, bleed, and artistic drawing

Free in Base Node, and what the pack adds

Free and open source, on the Base Node site: the language, the Blender add-on, the formatter and parsers, and the free modules of the standard library. The pack's modules build on the free module math. The pack adds the modules above, their showcase files and this tutorial.

Base Node VS Geo-Scatter

Geo-Scatter, by BD3D Digital Design. A paid scattering add-on for Blender: each scatter is a Geometry Nodes scatter object, set up from its panels. The free Biome-Reader reads and scatters its biomes.[1,2,3]

Base Node is a text language for Blender's node trees, with a free add-on and paid packs of tested node groups. Geo-Scatter is itself a Blender add-on, with panels, brushes and a biome library. Base Node's Scatter & Biomes works one level down: the scatter is a set of Geometry Nodes groups you write and read as .bn text, with its rules in plain sight. Both scatter inside Blender; they differ in how you drive them.

Of the 5 capabilities below, Base Node covers 1, covers 4 in part and does not cover 0. The Geo-Scatter side of each row was checked on BD3D Digital Design's pages on 2026-11-20; the numbers link to them.

Where Geo-Scatter is ahead

  • Manual mode paints, erases, moves and turns instances with about 30 viewport brushes.[13]
  • Physics mode places instances with a rigid-body simulation.[4]
  • Biomes build a full environment from vendor asset packs in one click.[3]
  • Display modes, a camera LOD of up to 5 levels and count limits keep the viewport fast.[12]
  • Panels for every feature, with documentation, example files and videos.[14]

When to choose which

  • Choose Geo-Scatter when

    You want panels and presets, manual brushes to paint instances, physics placement and ready-made biomes from asset vendors.

  • Choose Base Node when

    You want the rules themselves: a scatter you can read, diff and change in text, layers that keep their distance from each other, camera culling and LOD in the same graph.
